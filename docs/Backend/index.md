# 后端工程学习路线

后端工程关注的不只是接口能否返回结果，还包括数据正确性、并发、性能、安全、故障恢复和长期维护成本。

## 01 / Web 与数据基础

- 语言与工程：Python / Java / C++、包管理、配置、日志和测试。
- Web：HTTP、REST、鉴权、参数校验、错误处理与接口文档。
- 数据库：关系模型、SQL、索引、事务、锁和慢查询。
- 缓存：Redis、过期策略、缓存一致性和击穿处理。

阶段项目：完成一个带用户鉴权、分页查询、数据库迁移和 Redis 缓存的内容服务。

## 02 / 可靠性与异步任务

学习连接池、并发控制、消息队列、任务重试、幂等、限流和熔断。用自动化测试覆盖主流程、错误路径与边界条件。

阶段项目：将耗时任务移入队列，提供任务状态查询，并记录失败原因和重试次数。

## 03 / 部署与可观测性

使用 Docker 固化环境，通过 CI/CD 自动构建与部署；为服务加入结构化日志、指标、Trace 和告警。能从一次慢请求追踪到具体服务、SQL 或外部 API。

## 04 / 与 Agent 系统结合

Agent 服务需要后端提供模型网关、任务队列、会话状态、记忆、知识库、文件处理、权限控制与评估数据。先保证底层服务可靠，再增加复杂的规划和多 Agent 协作。
