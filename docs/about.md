# 你好，我是 MU-ty

我喜欢写代码，也喜欢把学习过程中的问题和思路记录下来。这份博客是我的个人知识库：既收集算法题解，也整理深度学习的基础知识。

## 我在关注什么

- **算法与数据结构**：理解题目背后的模式，记录复杂度、边界条件和不同解法。
- **深度学习**：从数学基础、损失函数和优化方法出发，逐步理解网络结构。
- **前端与 Agent**：通过实践探索界面设计和智能工具。
- **开源协作**：关注并参与 [LT 项目](https://github.com/hust-open-atom-club/LT)。

## 怎样阅读本站

如果你第一次来，可以从[学习路线](learning-paths.md)选择一个方向。已经有明确问题时，使用顶部搜索，或者直接进入[算法笔记](leetcode/index.md)和[深度学习笔记](<Deep Learning/index.md>)。

笔记中的代码、推导和个人理解都可能继续修订。遇到问题时，欢迎在[博客仓库](https://github.com/MU-ty/mty_blog/issues)提出具体反馈：页面名称、疑问所在的段落，以及你认为需要补充的例子，会让讨论更有效。

## 我的记录方式

理解一个概念时，我会尝试回答三个问题：

1. 它想解决什么问题？
2. 为什么这个方法有效，依赖哪些前提？
3. 能否写出一个最小例子，并解释失败的情况？

本站新增的导读和基础教程用于串联已有笔记。阅读时仍建议结合原始题目、教材和实际运行结果，形成自己的理解。
