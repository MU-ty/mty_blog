# 你好，我是 MU-ty

我喜欢写代码，也喜欢把学习过程中的问题和思路记录下来。这份博客是我的个人知识库，主要围绕后端工程和 AI Agent，也持续整理算法与模型基础。

## 我在关注什么

- **后端工程**：关注 API、数据库、缓存、异步任务、可靠性与部署。
- **AI Agent**：研究工具调用、上下文工程、RAG、Runtime、评估与多智能体协作。
- **算法与模型基础**：为工程实践补齐数据结构、复杂度、深度学习与注意力机制。
- **开源协作**：关注并参与 [LT 项目](https://github.com/hust-open-atom-club/LT)。

## 怎样阅读本站

如果你第一次来，可以从[学习路线](learning-paths.md)选择后端或 Agent 主线。已经有明确问题时，可以使用顶部搜索，或直接进入[后端专题](Backend/index.md)、[Agent 专题](Agent/index.md)和[算法笔记](leetcode/index.md)。

笔记中的代码、推导和个人理解都可能继续修订。遇到问题时，欢迎在[博客仓库](https://github.com/MU-ty/mty_blog/issues)提出具体反馈：页面名称、疑问所在的段落，以及你认为需要补充的例子，会让讨论更有效。

## 我的记录方式

理解一个概念时，我会尝试回答三个问题：

1. 它想解决什么问题？
2. 为什么这个方法有效，依赖哪些前提？
3. 能否写出一个最小例子，并解释失败的情况？

本站新增的导读和基础教程用于串联已有笔记。阅读时仍建议结合原始题目、教材和实际运行结果，形成自己的理解。
