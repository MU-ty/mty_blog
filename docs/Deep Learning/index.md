## 读公式时，先问这四件事

1. **对象**：符号代表标量、向量还是矩阵？
2. **形状**：运算前后的维度是否一致？
3. **目标**：公式在预测、损失还是参数更新中起作用？
4. **直觉**：输入或参数变化时，结果应该怎样变化？

例如线性层中的矩阵乘法，不只是公式变换，也是在把输入特征映射到输出空间。先标记每个维度，再代入小矩阵手算，通常比直接记忆更容易理解。

## 训练实验的记录模板

| 项目 | 需要记录的内容 |
| --- | --- |
| 任务与数据 | 预测目标、训练/验证划分、预处理方法 |
| 模型 | 层数、隐藏维度、参数量与输入输出形状 |
| 优化 | 损失函数、学习率、批大小、优化器 |
| 结果 | 训练和验证指标、异常现象、失败样本 |
| 复盘 | 改动了什么、观察到什么、下一次验证什么 |

!!! note "一次只改变一个主要变量"
    若同时改变模型、学习率和数据处理方式，很难解释结果变化来自哪里。先建立简单基线，再逐项比较。
