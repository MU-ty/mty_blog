# 学习路线

先选一条主线，再通过小练习检验理解。下面的路线对应本站已有笔记，不要求一次读完全部内容。

!!! tip "怎样使用这份路线"
    每次选择一个主题：先读概念，再独立写代码，最后用边界案例复盘。能解释“为什么”，比完成阅读更重要。

## 路线一 · 算法与数据结构

### 01 / 建立基本解题工具

| 主题 | 从哪里开始 | 练习目标 |
| --- | --- | --- |
| 哈希 | [两数之和](leetcode/哈希/0001.两数之和.md) | 区分“已遍历的信息”和“还需要寻找的信息” |
| 双指针 | [移动零](<leetcode/双指针/0283. 移动零.md>) | 解释每个指针负责什么，哪些位置已处理完成 |
| 滑动窗口 | [子数组最大平均数](<leetcode/滑动窗口/643. 子数组最大平均数 I.md>) | 用增量更新代替反复计算窗口和 |
| 链表 | [反转链表](<leetcode/链表/0206. 反转链表.md>) | 画出修改指针前后的连接关系 |

### 02 / 理解结构与不变量

接着阅读[二分查找导读](leetcode/二分查找/引入.md)、[二叉树导读](leetcode/二叉树/引入.md)和[有效的括号](leetcode/栈/0020.有效的括号.md)。

每道题都写下：循环结束前一直成立的条件、输入规模变化后的复杂度，以及空输入、单元素和重复元素的表现。

### 03 / 进入进阶专题

- [二叉堆](leetcode/补充/二叉堆.md) → [优先队列](leetcode/补充/优先队列.md)：处理“反复取出最优元素”的问题。
- [KMP](leetcode/补充/KMP算法.md)：把已经得到的前缀信息用于下一次匹配。
- [树状数组](leetcode/补充/树状数组.md) → [线段树](leetcode/补充/线段树.md)：比较不同动态区间查询结构的能力与代价。

## 路线二 · 深度学习

### 01 / 补齐数学与模型基础

建议顺序：[线性代数](<Deep Learning/1.线性代数.md>) → [概率统计](<Deep Learning/2.概率统计.md>) → [导数与反向传播](<Deep Learning/3.导数、反向传播、复杂度.md>) → [线性方法与 softmax](<Deep Learning/4.线性方法、基础优化和 softmax 回归.md>)。

学习目标不是记住全部公式，而是能解释输入、参数、预测、损失和梯度之间的关系。

### 02 / 理解训练为什么成功或失败

阅读[多层感知机](<Deep Learning/6.多层感知机.md>)、[模型选择与正则化](<Deep Learning/7.模型选择，欠拟合与过拟合，权重衰减 和 丢弃法.md>)、[计算图](<Deep Learning/8.前向传播、反向传播、计算图.md>)和[数值稳定性](<Deep Learning/9.数值稳定性、模型初始化.md>)。

尝试回答：训练误差和验证误差为什么可能不同？梯度太大或太小会怎样？哪些操作可能导致数值溢出？

### 03 / 连接不同网络结构

从[卷积神经网络](<Deep Learning/12.卷积神经网络.md>)进入视觉模型，再阅读[序列模型](<Deep Learning/15.序列模型.md>)和[注意力机制](<Deep Learning/16.注意力机制.md>)。

比较各类模型处理的信息：局部空间结构、序列顺序、位置之间的关联。用一个具体任务说明你选择这种模型的理由。

## 一份可复用的复盘清单

- [ ] 我能用自己的话描述这个问题。
- [ ] 我知道方法成立的前提与限制。
- [ ] 我能从零写出一个最小实现或算例。
- [ ] 我检查过边界条件、复杂度或张量形状。
- [ ] 我记录了一个仍然没想清楚的问题。

遇到卡点时，回到更小的例子。下一步可以先浏览[算法专题目录](leetcode/index.md)或[深度学习导读](<Deep Learning/index.md>)。
