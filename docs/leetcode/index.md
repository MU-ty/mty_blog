## 一道题的阅读顺序

1. 明确输入、输出和约束，写出最直接的解法。
2. 找到重复工作：重复搜索、重复求和，还是重复遍历？
3. 说明改进方法保存了哪些信息。
4. 用小案例走一遍，再检查空输入、重复值和极端边界。
5. 比较时间复杂度、空间复杂度与代码维护成本。

!!! tip "独立复现比直接复制更有效"
    读懂题解后关闭页面，重新写一遍。若卡住，记录具体缺失的推理，再回到对应段落。
